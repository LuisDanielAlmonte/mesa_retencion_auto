# mesa_retencion_auto
Presentaciones de la mesa de retencion de Auto - Humano Seguros

## Exportar
En la barra de controles (abajo, tecla **C** para fijarla) están los botones **PDF** y **PPT**.
Exportan los slides visibles (los ocultos desde ☰ no salen), con una página por plan en los slides de tendencia.
El PowerPoint es totalmente editable: textos, formas y gráficos son objetos nativos (`exportar-pptx.js`), no imágenes.
Usa la fuente Outfit (gratis en Google Fonts); si no está instalada, PowerPoint usa una parecida.
